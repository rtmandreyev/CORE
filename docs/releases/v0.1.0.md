# CORE v0.1.0

The first public release. CORE defines a visual theme once and previews or
applies it across the macOS apps you have.

## What's included

- **One file per theme.** `themes/<id>/theme.toml` holds the palette, the
  semantic roles, the terminal colours and per-app mappings. Application
  templates are shared, so a new theme needs no Python and no copied templates.
- **Six built-in themes:** OPTICAL, SHELL, EMBER, GLACIER, AUGMENT, NEON.
- **Automatic theming** for Ghostty, macOS Terminal, Starship, Fastfetch,
  VS Code, Hermes (CLI and Desktop) and Obsidian.
- **ChatGPT export/import:** `core export <theme> chatgpt --copy` produces
  ChatGPT's own theme string for *Settings → Appearance → Import*. Verified in
  the ChatGPT app.
- **Optional macOS light/dark switching**, which Claude Desktop follows when set
  to *Match System*.
- **An interactive terminal app** (`core`) and one-shot commands.
- **Reversible preview:** `core preview` restores the exact previous state on
  Enter, Ctrl-C or a closed terminal, and verifies the restore.
- **Transactional apply:** checks first, journals before writing, verifies after,
  and rolls back on any failure or interruption. `core restore` recovers from a
  killed process.
- **Doctor and repair:** `core doctor` is a read-only diagnosis. `core repair`
  restores CORE-owned files an app update removed (Hermes skins, the VS Code
  base extension, Ghostty theme files, Terminal profiles, vault themes).
- **Theme authoring:** `core theme new <name> --from <theme>`, edit one file,
  `core build`, `core preview`, `core apply`.

## Requirements

macOS and Python 3.11 or newer. No third-party packages. None of the supported
apps is required.

## Known limitations

- VS Code may need one window reload after the first apply installs CORE's
  base extension.
- Obsidian switches open vaults live only with its CLI enabled; the vault
  chooser window can't be themed.
- Hermes Desktop's built-in terminal pane keeps its own selection colour.
- ChatGPT needs one manual import per theme.
- Claude Desktop's font and code theme aren't managed; only light/dark,
  through macOS.
- Terminal keeps CORE profiles installed after you switch away.
- macOS only.
